# Push Personal DJ Context as Derived Summaries

Personal DJ Context will be pushed from the user's local personal context system into Crossfadio as derived DJ-specific summaries, authenticated by user-scoped Bridge Tokens. Crossfadio will not directly query local LifeMesh data, will not use a global ingest key, and will not store raw LifeMesh bundle content. This preserves the local privacy boundary while still letting the online DJ use current personal state and recent change signals for music selection and segue tone.
