# Player UI 重设计 — 设计文档

**日期：** 2026-04-28  
**状态：** 已批准，待实现

---

## 目标

将播放页面的主要元素集中在一屏内显示，删除调试/冗余信息，提升日常使用体验。

---

## 整体布局

从原来的三栏（左侧边栏 2 列 + 中间 7 列 + 右侧 3 列）改为：

```
┌─────────────────────────────────────────────────────┐
│  HEADER（全宽，高约 56px）                           │
│  [Logo + Crossfadio]  [今日计划] [设置]  [NCM chip] │
├──────────────────────────┬──────────────────────────┤
│  LEFT  col-span-6        │  RIGHT  col-span-6       │
│                          │                           │
│  NowPlayingHero          │  播放队列（占主要高度）   │
│  ──────────────          │                           │
│  歌词面板                 │  ──────────────────────  │
│  ──────────────          │  状态指示器（小）         │
│  进度条 + A→B 指示        │  重新开始DJ模式（小按钮）│
│  ──────────────          │                           │
│  播放控制                 │                           │
└──────────────────────────┴──────────────────────────┘
```

---

## 各区块规格

### Header（顶栏）

- **左侧：** Logo 图标 + 文字 "Crossfadio"（去掉版本号 "M1-07 Player MVP"）
- **右侧：** 今日计划按钮、设置按钮（图标按钮）、NCM 状态 chip
- **NCM 状态 chip（默认收起）：**
  - 收起状态：彩色圆点（绿=已登录，红=未登录）+ 短文字（"已登录" / "未登录"）
  - 点击展开 dropdown，内含完整登录控件（二维码、登录/登出按钮、检查状态）
  - 原左侧边栏整体移除

### 左栏 — NowPlayingHero

- 封面图：`w-16 h-16`（64×64px），圆角，无占位符文字
- 右侧：标题（xl 字号）、艺术家（sm，zinc-400）、喜欢按钮（红心图标）
- **删除：** NCM ID、crossfade timing、direct link status、"DJ Deck A" badge

### 左栏 — 歌词面板（SyncedLyrics）

- 固定高度：`h-48`，内容超出时内部滚动，隐藏滚动条（`scrollbar-hide`）
- 上下边缘添加渐隐遮罩（`mask-image: linear-gradient`）
- 无歌词时显示简短提示文字，不展开空白区域

### 左栏 — 进度条 + A→B 过渡指示

取代原来整个"双 Deck 混音台"卡片区，改为两行：

**行1（进度条行）：**
```
当前时间  ──────[range input]──────  总时长
```

**行2（过渡信息行，小字）：**
```
A: 歌曲名  ──✕──  B: 下一首名  ·  Xs 后切换
```
- 字号 `text-xs`，颜色 `text-zinc-500`
- X-FADE 符号用 `✕` 或 `×`，配合 amber→violet 渐变色
- 无下一首时该行隐藏

### 左栏 — 播放控制（TransportControls）

- 上一首 / 播放暂停 / 跳过，三个按钮水平居中
- 样式不变（amber 高亮播放键）

### 右栏 — 播放队列（QueuePanel）

- 占右栏顶部，`flex-1` 撑满可用高度，内部滚动
- 当前曲目：violet 高亮；下一首：cyan 文字；其余正常色
- 保留点击切换功能

### 右栏 — 状态区

- **状态指示器：** 曲目 / DJ选歌 / 过渡文案，三个 chip 横排
  - 每个 chip：小圆点（颜色表示状态）+ 短文字
  - 字号 `text-xs`，颜色次要（zinc-500）
- **"重新开始 DJ 模式" 按钮：** 次要样式，小尺寸，不抢眼

---

## 删除的内容

| 元素 | 原位置 | 删除原因 |
|------|--------|----------|
| 预取状态面板 | 右侧边栏 | 纯调试信息 |
| 双 Deck 混音台卡片 | 中间主区 | 占用面积过大，简化为一行文字 |
| 原左侧边栏（整体） | 左侧 2 列 | 导航和 NCM 面板合并到 header |
| 版本号文字 | 左侧 header | 无日常使用价值 |
| NCM ID / crossfade timing 等技术字段 | NowPlayingHero | 用户不关心 |
| "正在播放" 大标题 + 副标题 | 中间顶部 | 显而易见，无需重复 |

---

## 技术说明

- 布局：`grid grid-cols-12` → header `col-span-12`，左栏 `col-span-6`，右栏 `col-span-6`
- NCM chip 展开使用 React `useState` 控制，dropdown 用绝对定位浮层
- 歌词遮罩：CSS `mask-image` 或 Tailwind 自定义工具类
- A→B 过渡行数据来源：现有 `playbackTiming` 和 `nextTrack` state，无需新增接口
- 所有现有组件文件保留，仅修改 `PlayerView.tsx` 的布局骨架和各组件的 props/样式
